## Drafted single-shot Big Five scoring prompt (~380 tokens)

```
You are a psychometric scorer for the Synthius-Mem persona memory system. Given
a conversation transcript about the focal persona, produce Big Five personality
scores (per Costa & McCrae, 1992) with evidence quotes from the transcript.

Output format (strict JSON):
{
  "framework": "big_five",
  "persona_id": "<string>",
  "scored_at": "<ISO-8601 timestamp>",
  "traits": {
    "openness":         {"score": 0-100, "confidence": 0-1, "top_evidence": [<up to 3 verbatim quotes from transcript>]},
    "conscientiousness": {"score": 0-100, "confidence": 0-1, "top_evidence": [<quotes>]},
    "extraversion":     {"score": 0-100, "confidence": 0-1, "top_evidence": [<quotes>]},
    "agreeableness":    {"score": 0-100, "confidence": 0-1, "top_evidence": [<quotes>]},
    "neuroticism":      {"score": 0-100, "confidence": 0-1, "top_evidence": [<quotes>]}
  },
  "facets": []  // optional; leave empty unless strong signal
}

Guidelines:
  - Scores are 0-100 (50 = population median; 0 = very low; 100 = very high).
  - `top_evidence` quotes MUST be verbatim substrings of the transcript — do
    not paraphrase. Each quote should directly support the score.
  - `confidence` reflects how strongly the transcript supports the score.
    Use evidence count as a heuristic: 3+ supporting utterances → 0.7+;
    1-2 utterances → 0.4-0.6; ambiguous → <0.4.
  - If transcript is silent on a trait, emit score=50 with confidence<0.3 and
    empty top_evidence list.
  - Emit strict JSON only, no prose.
```

## Notable findings

1. **Evidence-quote grounding is robust.** 19/19 quotes across 3 runs are verbatim substrings of the 15-message fixture. The LLM did not paraphrase, compress, or invent quotes. This is a strong positive signal for the paper's "evidence quotes" claim (§3.3) — single-shot LLM scoring CAN produce verifiable grounding without a post-hoc quote-attribution step. The citation verification path (H-078) is implementable as exact-string matching.

2. **Observer quotes count as evidence.** The scorer correctly included Friend's observations about Jamie ("You seemed fine at Rachel's birthday", "You're always diving into weird art theory") as evidence. This is defensible — external observer ratings are standard in psychometric methodology — but the paper (§3.3) does not explicitly address whether Synthius-Mem's scoring accepts observer statements or restricts to self-reported evidence. This is a small policy-gap worth noting (G-???-new).

3. **Mid-range scores paired with low confidence.** Run 1 and Run 2 both scored agreeableness at 50-52 with confidence 0.40-0.45 — appropriate for a fixture with mixed signals (forgetful with Lisa but shows up for Rachel's birthday). The confidence-low flag correctly tracks evidence sparsity. This validates the T-008 display mapping (confidence < 0.5 → "low", routed to conservative display).

4. **Optional facets demonstrated feasible in one shot.** Run 3 populated facets (imagination 80, aesthetics 90, warmth 40, gregariousness 15, anxiety 70) alongside top-level traits, showing the hybrid T-005 schema is achievable without a second pass. Paper's silence on facets (E-007 PASS) is consistent with Synthius-Mem NOT using facets, but the architectural feasibility is here demonstrated — supporting H-008's optional-facet schema hybrid.

5. **Score stability across runs.** Cross-run variance on the same fixture: openness 82/85/83 (σ≈1.5), extraversion 22/20/23 (σ≈1.5), neuroticism 62/65/63 (σ≈1.5). Very low variance suggests single-shot scoring is stable enough for production use WITHOUT an EWMA blend (H-084). H-083 (re-derive from scratch at each consolidation) is favored over H-084 when per-run variance is this low.

6. **Caveat: LLM-self probe + synthetic fixture.** The fixture was designed by the runner with explicit cue-types (extraversion down, openness up). Real LoCoMo conversations lack such clean signals. Cross-model replication on real data is essential before extending the PASS finding.

7. **Implicit tension with paper's §5.3 "unvalidated" disclaimer.** The paper (§5.3 Limitations) says "the psychological profiling subsystem requires separate validation against ground-truth assessments from validated psychometric instruments." This probe produces *directionally-correct* scores on synthetic data but does NOT validate against NEO-PI-R ground-truth for real subjects. The PASS finding here is on *architectural feasibility and schema-validity*, NOT on *measurement validity*. The paper's caveat is correctly preserved.
