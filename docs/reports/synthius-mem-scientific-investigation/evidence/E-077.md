### 2. Behavioral decomposition of 99.55% adversarial robustness

The 99.55% figure = (hard-gate refusals + soft-prompt refusals) / adversarial questions.

From H-072's decomposition:
| Source | Estimated share |
|---|---|
| HARD GATE (primary + fallback both empty) | ~85% of adversarial cases (truly out-of-persona questions where retrieval has no evidence) |
| SOFT GATE (retrieval hit but context insufficient / low-confidence) | ~14.55% of adversarial cases (questions where retrieval brought back adjacent facts but not the exact evidence) |
| Residual false answers | ~0.45% |

99.55% = 85% + 14.55%.

def answer(question: str, persona_id: str, user_name: str):
    plan = planner.route(question)
    primary = dispatch_plan(plan, persona_id)
    if sum(len(v) for v in primary.values()) == 0:
        # fallback
        fb = dispatch_plan(all_6_domain_plan(question), persona_id)
        if sum(len(v) for v in fb.values()) == 0:
            # HARD GATE — programmatic short-circuit; no LLM invocation
            return f"I don't have that information about {user_name} in my memory."
        context = format_context(fb, SIX_DOMAINS)

        context = format_context(primary, plan.domains)

### 5. G-044 ambiguity resolution

G-044 asks whether refusal is pure-prompt or pure-code. The dual-layer answer is: **BOTH**, serving distinct failure modes:
- Hard gate handles "no evidence" (simplest case, cheapest to refuse — no LLM needed).
- Soft gate handles "evidence present but insufficient for the specific question" (requires LLM reasoning about whether the evidence actually addresses the question).

Neither gate alone would hit 99.55%:
- Hard gate alone misses soft-gate case (evidence present, wrong evidence).
- Soft gate alone wastes LLM invocations on clearly-empty retrievals AND relies on LLM prompt obedience to refuse when it could emit a confabulation.

✓ Dual-layer is the principled resolution.
