### 1. Re-derive-on-consolidation policy

```python
def score_persona_on_consolidation(persona_id: str, consolidation_seq: int):
    """Called once per consolidation batch. Re-scores ALL 9 frameworks
    from the FULL current evidence corpus (not incremental delta)."""
    frameworks = ["BigFive","Schwartz","MFT","PoliticalCompass","PANAS",
                  "VIA","IRI","Kohlberg","CognitiveAbility"]

    all_evidence = load_evidence_corpus(persona_id)  # all messages + facts to date

    for fw in frameworks:
        new_score = llm_score(
            framework=fw,
            evidence=all_evidence,
            model="gpt-4.1-mini",
            temperature=0.0)       # deterministic given inputs + seed

        # Append to event log (H-064) — old versions preserved
        append_event(persona_id, op='edit', domain='psychometrics',
                     fact_id=f"psy_{fw.lower()}",
                     before=current_score(persona_id, fw),
                     after=new_score,
                     extractor_version=SCORER_VERSION,
                     user_initiated=False)
```

### 3. Idempotent under temperature=0

- LLM scoring call with `temperature=0` + same model + same prompt + same evidence corpus → same output (up to minor stochasticity in vendor-side batched inference; >99% reproducibility in practice).
- For strict determinism, pair with a fixed `seed` parameter where the vendor supports it (OpenAI Chat Completions does via `seed`).
- Even with residual minor stochasticity, the key property — same inputs → same score distribution with narrow variance — is preserved. ✓

### 4. Simplifies implementation (no stateful blending)

No EWMA memory. No alpha-tuning. No conditional logic for "first score" vs "nth score". A single scoring function. ✓

### 6. Computational cost at production scale

Per consolidation batch: 9 frameworks × 1 LLM call each = 9 calls/persona/batch.

Per-call cost:
- Input tokens: evidence corpus (compressed/sampled from all persona messages). Assume ~4K tokens per framework call (representative sample, not full corpus).
- Output tokens: ~400 (score + facet? + 3 evidence quotes per trait × 5 traits = ~400 tok).

At GPT-4.1-mini pricing ($0.4/M input, $1.6/M output):
- Per call: (4000 × $0.4/M) + (400 × $1.6/M) = $0.0016 + $0.00064 = $0.0022.
- Per persona per batch: 9 calls × $0.0022 = $0.02.

Per-persona-per-hour (hourly consolidation): $0.02/hr = ~$175/persona/year.

At N=200 LoCoMo personas: ~$35K/year total scoring cost — comparable to extraction cost but NOT prohibitive at this scale.

**Scaling concern:** At N=1M personas (production SaaS scale), $175M/year is clearly prohibitive. Mitigation options:
- Reduce scoring cadence (daily instead of hourly): -24× → $7.3M/year — still expensive.
- Skip frameworks that haven't changed (add-change-detection layer): -30-50% typical.
- Distill scoring model to a smaller/cheaper model after training on GPT-4.1-mini outputs.

At LoCoMo scale this is tractable. At true production scale it requires further optimization.
