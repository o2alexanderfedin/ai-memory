## Drafted Artifacts

### 1. Event-log schema (persistent, append-only)

```sql
CREATE TABLE persona_event_log (
  persona_id          UUID        NOT NULL,
  seq                 BIGINT      NOT NULL,          -- monotone per-persona
  op                  TEXT        NOT NULL CHECK (op IN ('add','edit','delete','tombstone','snapshot_marker','schema_migration')),
  domain              TEXT,                           -- NULL for snapshot_marker
  fact_id             UUID,                           -- NULL for snapshot_marker
  before              JSONB,                          -- NULL for add; prior state for edit/delete
  after               JSONB,                          -- NULL for delete; new state for add/edit
  timestamp           TIMESTAMPTZ NOT NULL DEFAULT now(),
  extractor_version   TEXT        NOT NULL,
  user_initiated      BOOLEAN     NOT NULL DEFAULT FALSE,
  snapshot_label      TEXT,                           -- populated only for snapshot_marker
  PRIMARY KEY (persona_id, seq)
);
CREATE INDEX idx_pel_persona_domain ON persona_event_log (persona_id, domain, seq);
CREATE INDEX idx_pel_fact           ON persona_event_log (persona_id, fact_id, seq);
```

### 2. Three rollback operations

```python
# (i) point-in-time read: replay ≤ seq N
def snapshot_at(persona_id, target_seq):
    state = {d: {} for d in SIX_DOMAINS}
    for entry in db.query(
        "SELECT * FROM persona_event_log WHERE persona_id=? AND seq<=? ORDER BY seq",
        persona_id, target_seq):
        if entry.op == 'add':    state[entry.domain][entry.fact_id] = entry.after
        elif entry.op == 'edit': state[entry.domain][entry.fact_id] = entry.after
        elif entry.op == 'delete' or entry.op == 'tombstone':
            state[entry.domain].pop(entry.fact_id, None)
    return state

# (ii) rollback last N operations: reverse-apply
def rollback_n(persona_id, n):
    last_n = db.query(
      "SELECT * FROM persona_event_log WHERE persona_id=? ORDER BY seq DESC LIMIT ?",
      persona_id, n)
    for entry in last_n:
        if entry.op == 'add':
            append_event(persona_id, op='delete', domain=entry.domain,
                         fact_id=entry.fact_id, before=entry.after, after=None,
                         user_initiated=True)
        elif entry.op == 'edit':
            append_event(persona_id, op='edit', domain=entry.domain,
                         fact_id=entry.fact_id, before=entry.after,
                         after=entry.before, user_initiated=True)
        elif entry.op == 'delete':
            append_event(persona_id, op='add', domain=entry.domain,
                         fact_id=entry.fact_id, before=None, after=entry.before,
                         user_initiated=True)

# (iii) named snapshot marker (a logical checkpoint, NOT a data copy)
def create_snapshot_marker(persona_id, label):
    append_event(persona_id, op='snapshot_marker', domain=None, fact_id=None,
                 before=None, after=None, snapshot_label=label)
```

### 3. GDPR Art. 17 erasure path

```python
def gdpr_erasure(persona_id):
    # Phase 1: tombstone all current facts for the persona
    for domain in SIX_DOMAINS:
        for fact_id in list_current_fact_ids(persona_id, domain):
            append_event(persona_id, op='tombstone', domain=domain,
                         fact_id=fact_id, before=None, after=None,
                         user_initiated=True)
    # Phase 2: compaction (blow away ALL log entries for this persona_id
    # AND current snapshot rows, preserving only the final tombstone marker
    # as evidence the erasure was processed — then crypto-shred per-persona
    # encryption key under T-020 SQLite-per-persona; log entries become
    # permanently unreadable).
    db.execute("DELETE FROM persona_event_log WHERE persona_id=? AND op<>'tombstone'", persona_id)
    for domain in SIX_DOMAINS:
        db.execute(f"DELETE FROM {domain} WHERE persona_id=?", persona_id)
    crypto_shred_key(persona_id)
```

Unbounded by default. Optional per-tenant compaction policy (e.g., "collapse >90-day-old operations into a periodic snapshot") is available as a deployment knob but not a schema commitment.

## Checks performed

**(a) Schema `{persona_id, seq, op, domain, fact_id, before?, after?, timestamp, extractor_version, user_initiated}`:** Matches spec; `snapshot_label` added for snapshot markers. ✓

**(b) Three rollback operations implementable:** Point-in-time (forward replay), rollback-N (reverse-apply), named-snapshot (marker event). All implementable from the single log. ✓

**(c) GDPR Art. 17 via tombstone + compaction + crypto-shred:** Per-persona physical deletion + key destruction renders data permanently irrecoverable. ✓

**(d) Retention unbounded by default:** No mandatory compaction schedule. ✓

**(e) Idempotent replay — 5-entry synthetic fixture:**

```
seq=1: add    biography  f01 after={degree:"BSc", ...}
seq=2: add    work       f02 after={employer:"Acme", ...}
seq=3: edit   biography  f01 before={degree:"BSc",...} after={degree:"MSc",...}
seq=4: delete work       f02 before={employer:"Acme",...}
seq=5: add    biography  f03 after={degree:"PhD", ...}
```

Replay → state = `{biography: {f01: {degree:"MSc"}, f03: {degree:"PhD"}}, work: {}}`.
Replay twice → identical state (same inputs, deterministic application). ✓
