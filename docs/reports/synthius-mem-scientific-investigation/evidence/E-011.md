## Display-Function Mapping

```python
def confidence_label(c: float) -> str:
    if c >= 0.8:  return "high"
    if c >= 0.5:  return "medium"
    return "low"  # [0, 0.5)
```

This converts stored float → "high/medium/low" display label on read. It is lossless in the display direction (every float maps to exactly one label).

The reverse (label → float) is many-to-one and must pick a representative:
```python

```
