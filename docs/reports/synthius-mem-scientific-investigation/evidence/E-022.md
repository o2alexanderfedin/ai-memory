## Evaluation vs. criterion

The criterion is a **joint PASS**: both sub-claims must have zero external-contradiction evidence.

**Sub-claim 1 — persona_id is UUIDv4:**
- Synthius.ai: no ID disclosure at all. Zero external statement of what ID format is used. No ULID/slug/snowflake appears; no UUID appears either. **No contradicting evidence, but no confirming evidence.**
- GitHub: no public Synthius repository exists. Zero ID-format evidence either way.
- Paper: abstract is silent (accessible fetches did not reach the §3 / App. A text). The investigator ledger's own GAPS.md G-010 flags the paper as silent on `personaId` format.
- Verdict for sub-claim 1: **zero evidence of contradiction, but also zero evidence of confirmation.** The criterion's exact PASS wording requires zero contradiction (which holds), but the informational basis is web-silence, not verification.

**Sub-claim 2 — Style is a feature dictionary (≤12 scalar fields):**
- Synthius.ai: makes no reference to a "Style" domain at all on the public pages. The paper (per Fig. 2 footer, cited in GAPS.md G-004) mentions "writing fingerprint for persona-consistent generation" but the public site does not reproduce this text.
- GitHub: no public repo to inspect.
- Industry literature: "writing fingerprint" in the applied-LLM space typically refers to a **classifier-derived representation** (REEF, HuRef, LLMmap), **not** a feature dictionary. This is mild ambient pressure against the feature-dict claim, but is about how researchers *detect* fingerprints, not how a persona memory system *stores them for generation-time prompt injection*.
- Verdict for sub-claim 2: **zero direct external contradiction of feature-dict, but zero external confirmation either.** Web-silence dominates.

Neither sub-claim was contradicted by external evidence. Neither sub-claim was confirmed by external evidence. The criterion's literal PASS wording ("returns zero evidence contradicting") technically holds — but this is a weak PASS: it comes from web-silence rather than positive confirmation.

## Verdict

OUTCOME: **INCONCLUSIVE**.

Rationale: the rules specify that when external-evidence searches return no relevant evidence after good-faith effort, the verdict is INCONCLUSIVE (not PASS, not FAIL), because web-silence does not disprove web-existence. We ran ≥6 queries and considered ≥10 URLs; the dominant result was silence on both ID format and Style representation. The strict literal reading of the criterion ("zero evidence contradicting") would yield PASS, but this would be a PASS by absence, not by confirmation — the kind of result the "INCONCLUSIVE not FAIL" rule explicitly warns against treating as a strong signal.

Concrete findings that shaped this call:
1. **No public Synthius GitHub repository exists** as of search date (2026-04-20). No synthius-mem, no Synthius org. The "calgo-lab/Synthius" repo is an unrelated synthetic-data toolkit.
2. **Synthius.ai publishes no technical detail** on ID format or Style representation. Only high-level architecture language and demo metrics.
3. **The authors' prior work is empty in this space** (see E-005) — there is no external prior artifact from which a UUIDv4 or feature-dict convention could have been inherited or disclosed.
4. **Industry default hints are mixed**: UUIDv4 remains a common default for multi-tenant random IDs, but ULID/UUIDv7 adoption is rising rapidly in memory-store and event-sourcing contexts. Absent a direct disclosure, there is no prior probability strong enough to treat the UUIDv4 claim as externally supported.

Implication: H-022 cannot be externally verified or refuted until Synthius releases code or expands documentation. The paper's silence on both personas_id format and Style representation (paper GAPS G-010 and G-004) is confirmed from the outside — these decisions live inside the codebase or unpublished design docs.

A stronger experiment would require either (a) a code release from Synthius, or (b) a paper-forensic pass on the full PDF (which this external-evidence method cannot perform — the binary-PDF limitation was hit during this run). Recommend routing this hypothesis through an artifact-construction or paper-forensic method for a decisive call.
