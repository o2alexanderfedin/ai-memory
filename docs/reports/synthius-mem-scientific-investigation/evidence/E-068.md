## Drafted Artifacts

### 1. Trigger heuristic

```python
SUMMARIZER_TRIGGERS = {
    # Fire if any of these hold for a (domain, category):
    "min_new_facts": 5,
    "major_structural_change": True,   # consolidation added/removed ≥3 facts
    "stale_days_since_last_summary": 90,
}

def should_summarize(category_state: CategoryState) -> bool:
    if category_state.new_facts_count >= SUMMARIZER_TRIGGERS["min_new_facts"]:
        return True
    if category_state.consolidation_delta_count >= 3:
        return True
    if category_state.days_since_last_summary >= SUMMARIZER_TRIGGERS["stale_days_since_last_summary"]:
        return True
    return False
```

### 2. Summarizer prompt shape

```python
SUMMARIZER_SCHEMA = {
  "type":"object","additionalProperties":False,
  "properties":{
    "narrative":{"type":"string","maxLength":2000},   # ~500 tokens
    "timeline":{"type":"array","items":{
      "type":"object","additionalProperties":False,
      "properties":{"event":{"type":"string"},"ts":{"type":"string","format":"date-time"}},
      "required":["event","ts"]
    }}
  },
  "required":["narrative"]
}

SUMMARIZER_PROMPT = """You are summarizing a user's {domain} facts in category
"{category}" into a coherent short narrative paragraph (≤500 tokens).

Include key milestones as a timeline array only for Experiences. For other
domains, omit timeline.

Consolidated facts:
{consolidated_fact_list_json}
"""
```

### 3. Storage extension (T-003 envelope)

```python
@dataclass
class CategoryNarrative:
    domain: str
    category: str
    narrative: str
    timeline: Optional[List[dict]] = None
    generated_at: str
    generator_version: str           # e.g., "gpt-4.1-mini@2026-04"
    source_fact_ids: List[str]       # provenance: which facts fed the narrative
```

Stored in a sibling table `category_narratives (persona_id, domain, category, narrative, timeline, generated_at, generator_version, source_fact_ids)` — NOT mixed into the domain fact tables. Read-time join is optional.

### 4. Refresh-cadence arithmetic

Assume a LoCoMo persona has ~200 facts across 6 domains, clustered into ~30 categories (rough average). Consolidation batches run, say, hourly during active conversations.

- Per-batch summarizer invocations (worst case — all 30 categories trigger): 30 LLM calls × ~500 tok output + ~300 tok input per category × 1 batch/hour.
- Realistic trigger rate: ~10–20% of categories meet trigger conditions per batch → 3–6 calls/batch.
- At GPT-4.1-mini pricing (~$0.4/M input, $1.6/M output): 6 calls × (300 in + 500 out) × $1/M ≈ $0.0048/persona/batch. Annualized at hourly batches: ~$42/persona/year.
- Absolutely negligible relative to extraction cost.

Cadence is **O(1) per consolidation batch** in practice (bounded by `max_categories × trigger_rate`), **NOT O(N_facts)**. ✓

### 5. Narrative size bounded at ~500 tokens/category

`maxLength: 2000` chars ≈ ~500 tokens (cl100k_base, English prose: ~4 char/token). The schema's `maxLength` enforces truncation at output; the prompt explicitly instructs ≤500 tokens. ✓
