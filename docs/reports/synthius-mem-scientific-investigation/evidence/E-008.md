## Drafted Hybrid Schema

```json
{
  "$id": "https://synthius-mem/schemas/psychometrics_hybrid.json",
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type":"object","additionalProperties":false,
  "required":["persona_id","schema_version","frameworks"],
  "properties":{
    "persona_id":{"type":"string"},
    "schema_version":{"type":"string"},
    "frameworks":{"type":"object","additionalProperties":{"$ref":"#/$defs/FrameworkBlock"}}
  },
  "$defs":{
    "FrameworkBlock":{"type":"object","additionalProperties":{"$ref":"#/$defs/TraitBlock"}},
    "TraitBlock":{"type":"object","additionalProperties":false,
      "required":["score","evidence_quote","confidence"],
      "properties":{
        "score":{"type":"number","minimum":0,"maximum":100},
        "evidence_quote":{"type":"string"},
        "confidence":{"type":"number","minimum":0,"maximum":1},
        "facets":{"type":"array","items":{"$ref":"#/$defs/Facet"}}
      }},
    "Facet":{"type":"object","additionalProperties":false,
      "required":["name","score"],
      "properties":{
        "name":{"type":"string"},
        "score":{"type":"number","minimum":0,"maximum":100},
        "evidence":{"type":"string"}
      }}
  }
}
```

Key: `TraitBlock.facets` is NOT in `required`, so it's optional per JSON-Schema semantics.

## Paper-Text Forbid/Require Check (§3.3 and §5.3)

§3.3: "Nine validated psychological frameworks—Big Five (Costa & McCrae, 1992), Schwartz Values (1992), PANAS (Watson et al., 1988), VIA Character Strengths, Cognitive Ability, IRI Empathy (Davis, 1983), Moral Foundations (Graham et al., 2013), Political Compass, and Kohlberg Moral Development (1981)—producing normalized scores with confidence ratings and evidence quotes, embedded in the system prompt for personality-consistent generation."

Check:
- "normalized scores" → plural but unquantified granularity
- "confidence ratings and evidence quotes" → no mention of facets, but also no prohibition
- NO text like "only trait-level scores" (would forbid facets)
- NO text like "all NEO-PI-R facets are scored" (would require facets)

§5.3: "the psychological profiling subsystem requires separate validation against ground-truth assessments from validated psychometric instruments." Unrelated to facet granularity.

**Conclusion:** Paper is silent on facets → both endpoints (minimal, maximal) are consistent with paper text.
