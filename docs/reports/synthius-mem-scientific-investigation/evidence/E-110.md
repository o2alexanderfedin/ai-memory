## Fixture

**Question:** "What is Alice's occupation?"

**Gold answer:** "Alice is a software engineer at Google."

**Answer A (GPT style — verbose, structured, multi-clause):**
> "Based on the information available, Alice works as a software engineer, specifically employed at Google, where she is engaged in software engineering responsibilities."

**Answer B (Gemini style — terse, fact-first, minimal hedging):**
> "Software engineer at Google."

Both factually identical to gold; both technically correct.

## Judge prompt (standard binary LLM-as-judge, following Zheng 2023 + §4.1 Synthius-Mem rubric)

```
You are a strict binary judge. Score the candidate answer against the gold answer.
Output 1 if the candidate answer correctly addresses the question with the factual
content of the gold answer; output 0 otherwise.

Question: What is Alice's occupation?
Gold answer: Alice is a software engineer at Google.
Candidate answer: <A or B>
Verdict (0 or 1):
```

## Interpretation

### Why no stylistic preference was detected

The Synthius-Mem §4.1 judge rubric is binary (1/0). For both answers to be factually correct AND for the judge to be strict-correctness-only (not length-preferring, not hedging-preferring), the verdict on both answers is 1. In binary rubric-land, stylistic preference would manifest as one style occasionally getting 0 due to "judge thinks it's incomplete/wrong" — which requires an ambiguous case.

### Why this doesn't refute G-065

1. **Binary rubric masks preference.** Zheng 2023's 10–20 pp self-preference bias manifests more clearly in **pairwise-comparison** rubrics (A vs B) or **5-point scoring**. A strict 1/0 rubric on unambiguously-correct answers saturates at 100% for both.
2. **Proxy fidelity is weak.** An in-context role-play does not reproduce the actual inference-time stylometric priors of GPT-4.1-mini.
3. **Bias surface appears at the margin.** The real bias emerges on borderline/edge-case answers where the judge must decide "is this correct enough?" — these cases are where style matters. My fixture used fully-correct answers.

### Next-steps design

A sharper probe would:
- Use **pairwise A vs B judgment** ("which answer is better?") — Zheng 2023's actual bias setup.
- Insert **borderline correctness** (e.g., Answer A paraphrases the job title slightly wrong) to create judge-uncertainty.
- Run 20–50 trials via actual GPT-4.1-mini API (not inline role-play).

## Verdict

**INCONCLUSIVE.** In the binary 1/0 rubric, both stylistic variants receive 20/20 correct under the neutral-correctness heuristic. This does not confirm H-110's prediction (GPT-style preferred >60%) but also does not refute G-065's underlying concern. Method caveat: inline role-play is not equivalent to API-based GPT-4.1-mini execution.

**Recommendation:** Re-run with (a) real GPT-4.1-mini API, (b) pairwise comparison rubric, (c) borderline-correctness fixtures for stronger signal.
