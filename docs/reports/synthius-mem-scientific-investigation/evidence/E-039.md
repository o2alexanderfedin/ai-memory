## Drafted context-assembler pseudocode

```python
from typing import Iterable
TOKENS_PER_ITEM = {                 # median FactItem token costs
  "biography": 80, "experiences": 140, "preferences": 70,
  "social_circle": 90, "work": 110, "psychometrics": 200,
}

def token_count(item) -> int:
    """Exact count via tiktoken.encode(json.dumps(item))."""
    return tiktoken_cl100k.encode_count(json.dumps(item, separators=(",",":")))

def assemble_context(
    per_domain_hits: dict[str, list[FactItem]],   # planner-selected domains
    cap_tokens: int = 2000,
) -> str:
    domains = list(per_domain_hits.keys())
    k = len(domains)
    if k == 0: return ""
    quota = cap_tokens // k                       # equal per-domain quota
    packed_blocks = []
    total = 0
    for d in sorted(domains):                     # stable domain order
        spent = 0
        block = [f"## {d}"]
        # (recency DESC, confidence DESC) — H-039 ordering primary
        hits = sorted(
            per_domain_hits[d],
            key=lambda h: (-h.updated_at, -h.confidence, h.fact_id),
        )
        for h in hits:
            serialized = json.dumps(h.to_compact(), separators=(",",":"))
            cost = token_count(serialized)
            if spent + cost > quota:              # atomic: never pack mid-item
                break
            block.append(serialized)
            spent += cost
        total += spent
        packed_blocks.append("\n".join(block))
    assert total <= cap_tokens, "per-domain quotas sum respects cap"
    return "\n\n".join(packed_blocks)
```

Key invariants:
- **Atomic item packing** — each fact is either fully in or fully out; no mid-JSON truncation (pass criterion d).
- **Deterministic ordering** — lexicographic (updated_at DESC, confidence DESC, fact_id ASC) per domain and alphabetic domain order for assembly.
- **Hard per-domain quota** — `spent + cost > quota` breaks the pack loop before overflow.
- **Global cap assertion** — `sum(spent) ≤ 2000` by construction (k × (2000//k) ≤ 2000).
