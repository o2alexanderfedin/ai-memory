### 1. Stage 1 — Deterministic text feature extraction

```python
import re, statistics
from nltk.tokenize import sent_tokenize, word_tokenize
from nltk.sentiment.vader import SentimentIntensityAnalyzer

# LIWC-style lexicon categories (public-domain replacements: Empath, NRC)
from empath import Empath

class TextFeatures:
    def __init__(self, corpus: List[str]):
        self.corpus = corpus
        self.sent_analyzer = SentimentIntensityAnalyzer()
        self.empath = Empath()

    def avg_turn_length(self) -> float:
        return statistics.mean(len(word_tokenize(t)) for t in self.corpus)

    def exclamation_rate(self) -> float:
        return sum(t.count("!") for t in self.corpus) / max(len(self.corpus), 1)

    def social_reference_rate(self) -> float:
        """Fraction of messages mentioning social entities (names, 'we','us')."""
        pattern = re.compile(r"\b(we|us|our|together|friend|family|team)\b", re.I)
        return sum(1 for t in self.corpus if pattern.search(t)) / len(self.corpus)

    def emotion_positivity(self) -> float:
        scores = [self.sent_analyzer.polarity_scores(t)["compound"] for t in self.corpus]
        return (statistics.mean(scores) + 1) / 2    # normalize [-1,1]→[0,1]

    def empath_categories(self) -> Dict[str, float]:
        # Aggregate Empath category counts across corpus
        agg = {}
        for t in self.corpus:
            for cat, cnt in self.empath.analyze(t, normalize=True).items():
                agg[cat] = agg.get(cat, 0) + cnt
        total_msgs = len(self.corpus)
        return {k: v/total_msgs for k,v in agg.items()}
```

### 2. Stage 2 — Per-framework scoring functions

```python
import numpy as np

def sigmoid(x): return 1 / (1 + np.exp(-x))

def score_extraversion(feats: TextFeatures) -> float:
    """Bounded 0-100 score with interpretable feature weights."""
    z = (0.35 * z_score(feats.avg_turn_length(),    mu=15, sigma=7)
       + 0.45 * z_score(feats.exclamation_rate(),   mu=0.3, sigma=0.5)
       + 0.40 * z_score(feats.social_reference_rate(), mu=0.25, sigma=0.2)
       + 0.20 * z_score(feats.emotion_positivity(), mu=0.5, sigma=0.15))
    return 100 * sigmoid(z)

def score_openness(feats: TextFeatures) -> float:
    cats = feats.empath_categories()
    z = (0.40 * z_score(cats.get("art", 0),      mu=0.02, sigma=0.03)
       + 0.30 * z_score(cats.get("science", 0),  mu=0.02, sigma=0.03)
       + 0.30 * z_score(cats.get("philosophy",0),mu=0.01, sigma=0.02)
       - 0.20 * z_score(cats.get("tradition", 0),mu=0.01, sigma=0.02))
    return 100 * sigmoid(z)
```

## FAIL-Clause analysis — CRITICAL

The FAIL criterion states:
> FAIL if §3.3's "producing normalized scores with confidence ratings and evidence quotes" is load-bearing for LLM-emitted evidence (features alone cannot produce evidence quotes)

§3.3 explicitly names "evidence quotes" as an output of the Psychometrics component. The paper text describes evidence quotes as contextual verbatim strings tied to specific traits — e.g., a message snippet that demonstrates extraversion like "I LOVE parties!!! Let's all go!!!".

A feature-extraction pipeline CANNOT produce evidence quotes. Feature-extraction produces scalars (exclamation rate, turn length, empath category frequencies). It cannot emit a *specific quote* tied to a *specific trait* — that requires LLM-level selection-with-reasoning.

One could bolt on a post-hoc "find the messages that most strongly activate this feature" heuristic (e.g., return the message with the highest exclamation count as the extraversion evidence), but this is (i) not meaningfully different from keyword search, (ii) known to produce brittle results that don't generalize across personas, and (iii) would not satisfy a reader who expected the published examples of trait-grounding evidence.

**The FAIL clause is triggered.** §3.3's evidence-quote language IS load-bearing for LLM-emitted evidence. A pure feature-pipeline cannot produce what the paper says the system produces.
