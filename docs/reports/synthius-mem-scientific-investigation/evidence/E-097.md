## Arithmetic

### 1. Per-request wall-clock latency

Synthius-Mem request path (§3, §4):
- 6-way parallel extraction (only on ingestion, not per-query): amortized as extraction overhead, not in hot path.
- Planner LLM call: ~500 ms (GPT-4.1-mini, ~1K in + ~100 out).
- Answer LLM call: ~1,500 ms p50 (GPT-4.1-mini, ~5K in + ~200 out).
- Retrieval: ~22 ms (§4.6).

Sequential total: 500 + 1500 + 22 ≈ **2,022 ms p50**. With planner→retrieval overlap: ~1,700 ms p50 effective wall-clock.

### 2. Per-instance RPS (LLM-call-bound)

With 1000 concurrent coroutines per instance (each awaiting LLM API):
- Each socket in-flight ~2 s
- Throughput = 1000 concurrent / 2 s = **500 RPS per instance (sustained)**

Backpressure constraints:
- OpenAI Tier 4 TPM quota: 2M TPM per org → 2M / 5040 tok/msg = 397 RPS (approximately matches the single-instance RPS ceiling).
- OpenAI Tier 5 TPM: 30M TPM → 5,952 RPS (scales further).

Instance is **LLM-provider-rate-limit bound**, not CPU-bound. A 4-vCPU instance at 500 RPS @ ~2 s/request has CPU utilization primarily from coroutine bookkeeping + JSON parsing ≈ 10-30% — NOT CPU-limited.

### 3. Per-persona storage cost

Per T-030 (p75 sizing): ~10 MB per persona (2.5 MB median).
- S3/OBS storage: $0.023/GB/month × 0.010 GB × 12 months = **$0.0028/persona/yr** (negligible)
- Postgres storage (JSONB + indexes): ~$0.05-0.10/GB/month on RDS = **$0.006-0.012/persona/yr**
- **Rounded: ~$0.01-0.02/persona/yr for raw storage.**

### 4. Per-persona LLM cost (usage-dependent)

Assumptions:
- 100 msg/mo typical active user × 12 = 1,200 msg/yr
- Per-message token cost = **5,040 tok/msg** (H-091 canonical)

**At GPT-4.1-mini pricing** ($0.15/M in, $0.60/M out; blended ≈ $0.18/M with 96/4 split):
- 5,040 × 1,200 × $0.18/M = 6,048,000 × $0.18/M = **$1.09/persona/yr**

**At GPT-5.4 pricing** ($2.50/M in, $15/M out; blended ≈ $3.00/M):
- 5,040 × 1,200 × $3.00/M = 6,048,000 × $3.00/M = **$18.14/persona/yr**

**At GPT-5.4 heavy use** (1,000 msg/mo = 12,000 msg/yr):
- 12,000 × 5,040 × $3.00/M = **$181.44/persona/yr**

**At GPT-4.1-mini light use** (10 msg/mo):
- 120 × 5,040 × $0.18/M = **$0.11/persona/yr**

### 6. Backpressure analysis

Rate-limit bound (per H-103 design):
- Per-tenant token bucket sized to provider TPM.
- Per-persona fairness sub-bucket (e.g., 10K tokens/min/persona) prevents noisy-neighbor saturation.
- Admission control SEPARATE from retry (Retry-After honored per T-041).

At 500 RPS × 5,040 tok/msg = 2.52M tokens/s = 151.2M TPM — well above any single-org OpenAI quota. Hence **provider rate-limit is the bottleneck**, not CPU or network, confirming the LLM-call-bound claim.
