## Arithmetic

### Test 1 — Table 7 per-message × N (canonical per H-091)

Paper §A.1 Table 7: Synthius-Mem total = **5,040 tok/msg** (1,000 sys + 2,000 retrieved + 1,100 planner + 740 extraction + 200 output).

- N=500:  5,040 × 500 = **2,520,000** tokens = **2.52M**
- N=1000: 5,040 × 1000 = **5,040,000** tokens = **5.04M**

Additionally, Table 11 independently labels Synthius-Mem at "~5,040 tok/msg Measured" (confidence: Measured), providing a second internal corroboration for the per-message figure.

### Test 2 — App. A.2 direct cumulative

Paper §A.2 verbatim: "At N=500: Synthius-Mem cumulative ≈ 4.7M tokens … At N=1000: ≈ 9.3M tokens."

- N=500:  4.7M / 500 = **9,400 tok/msg** (implied)
- N=1000: 9.3M / 1000 = **9,300 tok/msg** (implied)

Gap factor vs Table 7: 9,400 / 5,040 = **1.865×** inflation (consistent with doubling of extraction line-item or pre-amortization figure).

### Test 3 — USD back-solve from App. A.3 (the critical discriminator)

Paper §A.3: "GPT-5.4 pricing as of April 2026: $2.50/M input, $15/M output." Cumulative USD: $7.42 at N=500, $13.57 at N=1000.

**Input/output share** (per Table 7 + A.1):
- Input portion per message: 1,000 sys + 2,000 retrieved + 1,100 planner + 740 extraction = 4,840 tok
- Output portion per message: 200 tok
- Total: 5,040 tok
- Input share: 4,840 / 5,040 = **96.03%**
- Output share: 200 / 5,040 = **3.97%**

**Blended rate:**
- 0.9603 × $2.50/M + 0.0397 × $15/M
- = $2.4008/M + $0.5952/M
- = **$2.996/M ≈ $3.00/M blended**

**Back-solve at N=500:**
- $7.42 / $2.996/M = **2,477,303 tokens ≈ 2.48M**
- Gap vs Table 7-derived 2.52M: |2.48 − 2.52| / 2.52 = **1.79%** (within rounding)
- Gap vs App. A.2's 4.7M: |2.48 − 4.70| / 4.70 = **47.3%** (nearly half)

**Back-solve at N=1000:**
- $13.57 / $2.996/M = **4,529,372 tokens ≈ 4.53M**
- Gap vs Table 7-derived 5.04M: |4.53 − 5.04| / 5.04 = **10.1%** (close; extraction amortization continues below 740/msg floor at larger N is plausible)
- Gap vs App. A.2's 9.3M: |4.53 − 9.30| / 9.30 = **51.3%** (factor of 2 off)

**Savings-ratio cross-check** (paper text: "~2.5× at N=500, ~5.0× at N=1000"):
- $18.41 / $7.42 = **2.481×** ✓ matches "~2.5×"
- $68.28 / $13.57 = **5.032×** ✓ matches "~5.0×"

The USD figures are internally self-consistent at the Table-7-canonical-token level.
