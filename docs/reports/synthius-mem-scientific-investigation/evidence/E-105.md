## Arithmetic + Evidence

Per E-096 analysis:

- Commodity cloud instances (AWS t3.large, GCP n2-standard-2) easily achieve this.

**No specialized hardware required.** ✓ H-105 prediction (a) holds.

### 3. GPT-4.1-mini pricing comparison

Confirmed from OpenAI pricing docs (public):
- GPT-4.1-mini (released April 2025): $0.15/M input, $0.60/M output
- GPT-5.4 standard: $2.50/M input, $15/M output
- Ratio input: $2.50 / $0.15 = **16.7×** more expensive
- Ratio output: $15 / $0.60 = **25×** more expensive
- Blended (96/4 split): GPT-5.4 $3.00/M vs GPT-4.1-mini $0.18/M = **16.67×** more expensive

### 4. Cost re-computation at GPT-4.1-mini pricing

Per-conversation cost at N=500 with 5,040 tok/msg:
- Total tokens: 5,040 × 500 = 2.52M
- At GPT-5.4 blended $3.00/M: 2.52M × $3.00/M = **$7.56** (matches paper's $7.42, gap 1.87%)
- At GPT-4.1-mini blended $0.18/M: 2.52M × $0.18/M = **$0.45** per conversation

**GPT-4.1-mini is ~16.8× cheaper per conversation** than GPT-5.4 for the same token budget. H-105 prediction was "~15× cheaper" — actual is 16.8×, directionally correct and slightly above H-105's estimate.

### 5. Token-vs-USD primacy

H-105 argues token-per-message is the stable architecture-neutral metric; USD is provider-dependent. This remains correct:
- 5,040 tok/msg is the architecture's intrinsic cost.
- USD depends on which model you run (GPT-4.1-mini: $0.45/conv; GPT-5.4: $7.42/conv; future models: TBD).
- Synthius-Mem's token-efficiency advantage (~3-5× vs Full Context) is preserved regardless of model.

### 6. Implication for paper's cost analysis

The paper's use of GPT-5.4 pricing for USD figures is **legitimate** (GPT-5.4 is real). But it is **a conservative choice** — deploying on GPT-4.1-mini yields 16.8× lower USD cost per conversation. Readers making budgetary decisions should note:
- "$7.42 per 500-msg conversation" is a GPT-5.4 projection (realistic for 2026 flagship).
- On cheaper models (GPT-4.1-mini, Claude Haiku, Gemini Flash), the same architecture costs $0.45-$1.50 per conversation.
