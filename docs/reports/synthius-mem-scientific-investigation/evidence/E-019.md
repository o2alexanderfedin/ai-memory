## Drafted Dual-Storage Schema

```json
{
  "$id":"https://synthius-mem/schemas/biography_dual.json",
  "$schema":"https://json-schema.org/draft/2020-12/schema",
  "type":"object","additionalProperties":false,
  "required":["persona_id","facts"],
  "properties":{
    "persona_id":{"type":"string"},
    "facts":{"type":"array","items":{"$ref":"#/$defs/DualFact"}}},
  "$defs":{
    "DualFact":{
      "type":"object","additionalProperties":false,
      "required":["category","composite","fields"],
      "properties":{
        "category":{"enum":["education","employment","family","health","residence","nationality","religion","languages","relationships","finances","legal_status","military_service","hobbies","skills","achievements","beliefs","demographics","lifestyle","life_events"]},
        "composite":{"type":"string"},
        "fields":{"type":"object"},
        "confidence":{"type":"number","minimum":0,"maximum":1}
      }
    }
  }
}
```

Per-category strictness can be tightened via conditional `if/then/else` on category:
```json
{"allOf":[{"if":{"properties":{"category":{"const":"education"}}},
          "then":{"properties":{"fields":{"type":"object","additionalProperties":false,
            "required":["degree","field","institution","year"],
            "properties":{"degree":{"type":"string"},"field":{"type":"string"},
              "institution":{"type":"string"},"year":{"type":"integer"}}}}}}]}
```

## Fig. 2 Example Validation (Dual Form)

Input: `"PhD Neuroscience, UCL, 2019"`

```json
{
  "category":"education",
  "composite":"PhD Neuroscience, UCL, 2019",
  "fields":{
    "degree":"PhD",
    "field":"Neuroscience",
    "institution":"UCL",
    "year":2019
  },
  "confidence":0.95
}
```

Both `composite` and `fields` populated simultaneously. ✓

Additional validations:
- Residence: `{category:"residence", composite:"Lives in London", fields:{city:"London"}}` ✓
- Employment: `{category:"employment", composite:"Software engineer at Google since 2020", fields:{title:"Software engineer", employer:"Google", start_year:2020}}` ✓

## Storage Cost Implication (brief)

Dual storage doubles per-fact bytes (composite + fields). At LoCoMo-style scale (100-1000 facts × ~100 bytes each), overhead is negligible (~100 KB per persona). At 500 MB production scale, it is ~2× footprint but still well under storage budgets.
