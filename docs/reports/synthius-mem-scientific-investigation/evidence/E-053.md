## Drafted Artifacts

### 1. Chunk-rendering template

```python
def render_chunk(messages: List[Message]) -> str:
    speakers = sorted({m.speaker for m in messages})
    header = f"# Speakers present: {', '.join(speakers)}\n"
    body = "".join(f"[{m.speaker}:{m.ts}] {m.text}\n" for m in messages)
    return header + body
```

### 3. Speaker-aware extraction prompt fragment

```
You are extracting facts about {FOCAL_PERSONA}. The conversation below
has multiple speakers; only emit facts whose subject is {FOCAL_PERSONA}.

Rules:
1. If the focal persona states a fact in first person ("I got my PhD"),
   attribute the fact to them.
2. If another speaker states a fact about the focal persona in second
   person ("You studied at UCL"), attribute the fact to the focal persona.
3. If a speaker states a fact about someone OTHER than the focal persona,
   DO NOT emit it.
4. For each fact, set `provenance.source_message_id` to the `[Speaker:ts]`
   marker of the turn the fact was extracted from.
5. Output JSON matching the domain schema.

Speakers present in this chunk: {CHUNK_SPEAKERS}
Focal persona: {FOCAL_PERSONA}
```
