### 1. Misroute-recovery wrapper pseudocode

```python
def answer_with_fallback(question: str, persona_id: str) -> AnswerContext:
    plan = planner.route(question)                           # primary routing
    primary_results = dispatch_plan(plan, persona_id)        # T-025 tools
    primary_hits = sum(len(v) for v in primary_results.values())

    if primary_hits > 0:
        return AnswerContext(
            path="primary",
            domains=plan.domains,
            facts=primary_results,
            status="grounded")

    # No hits — try fallback: broaden to all 6 domains
    fallback_plan = Plan(
        domains=SIX_DOMAINS,
        per_domain_query={
            d: DerivedQuery.from_question(question, d) for d in SIX_DOMAINS
        })
    fallback_results = dispatch_plan(fallback_plan, persona_id)
    fallback_hits = sum(len(v) for v in fallback_results.values())

    if fallback_hits > 0:
        return AnswerContext(
            path="fallback",
            domains=[d for d,v in fallback_results.items() if v],
            facts=fallback_results,
            status="grounded_via_fallback")

    # True refusal — all six domains empty
    return AnswerContext(
        path="refusal",
        domains=[],
        facts={},
        status="no_evidence",
        refusal_reason="no_matching_facts")
```

### 3. Cost arithmetic

- Primary path (happy case): 1 planner call + K domain retrieval calls (K typically 1–3).
- Fallback (misroute case): adds 6 additional retrieval calls (not cumulative across domains — parallelized).
- Retrieval is a local index probe per T-022 (~1 ms per domain on 200K-row Postgres; sub-ms on SQLite per-persona).
- Parallel fanout: 6 retrievals in parallel bound by slowest ≈ 1-2 ms. Sequential would be ~6-10 ms.
- Planner call: NOT re-invoked — the fallback uses a deterministic `DerivedQuery.from_question` helper to enumerate all-domain predicates, avoiding a second LLM round-trip.
- **Total fallback overhead: ~2-10 ms on empty primary only.** Under ~50 ms target. ✓

Mean preservation: if miss-rate is <<1%, the mean latency shift is negligible. At 21.79 ms mean:
- Happy path (99% of traffic): unchanged.
- Fallback path (<1% of traffic): +10 ms ≈ 0.01 × 10 = 0.1 ms contribution to mean.
- New mean: ~21.89 ms, rounds to the published number. ✓

### 4. Refusal-rate preservation (99.55%)

Two-path refusal decomposition:

| Trigger | Path | % of adversarial queries |

Hard-gate refusals (85%) + soft-prompt refusals (14.55%) = 99.55%. ✓
