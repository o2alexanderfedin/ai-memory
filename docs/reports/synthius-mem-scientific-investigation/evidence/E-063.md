## Drafted Artifacts

### 1. Canonical `Message` dataclass

```python
from dataclasses import dataclass, field
from typing import List, Optional, Literal
import ulid

@dataclass(frozen=True)
class Attachment:
    type: Literal["image","voice","video","file","link"]
    uri: str
    mime: str
    description: Optional[str] = None

@dataclass(frozen=True)
class Message:
    message_id: str                # 26-char ULID — time-sortable + globally unique
    speaker: str                   # normalized display name
    ts: str                        # ISO-8601 UTC ("2024-03-15T10:22:01Z")
    text: str                      # plain-text body
    attachments: Optional[List[Attachment]] = None
    thread_id: Optional[str] = None  # email thread / group chat id
    source_format: str = ""        # "whatsapp" | "telegram" | "pdf" | "email"

def new_message_id() -> str:
    return str(ulid.new())   # time-sortable ULID
```

### 2. Adapter round-trip check (maps to H-051 output)

Every H-051 adapter emits a proto-`Message` lacking `message_id`; a post-process assigns ULID:

```python
def finalize_adapter_output(raw_messages: Iterable[dict]) -> List[Message]:
    out = []
    for r in raw_messages:
        out.append(Message(
            message_id=new_message_id(),
            speaker=r["speaker"], ts=r["ts"], text=r["text"],
            attachments=[Attachment(**a) for a in r.get("attachments",[])] or None,
            thread_id=r.get("thread_id"),
            source_format=r.get("source_format","")))
    return out
```
