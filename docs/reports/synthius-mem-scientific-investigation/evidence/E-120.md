## Rhetoric-vs-evidence table (3+ instances required)

### Mismatch 1 — §5.3 "market converged" vs same-section "divergent prompts"

**Rhetoric (§5.3):** "To ensure cross-paper comparability we commonly use; results are in Section 4.2 and demonstrate that our lead is judge-robust." [Implicit "market converged on LLM-as-judge" framing.]

Also §4.1 / §4.4 discussions frame GPT-4.1-mini LLM-as-judge as standard practice.

**Evidence (same §5.3):**
> "different research groups employ substantially different evaluation prompts. The original LoCoMo paper (Maharana et al., 2024) uses token-overlap F1. Mem0 (Singh et al., 2025) instructs its judge to 'be generous with grading.' Hippocampus uses a 5-point scale. ENGRAM's evaluation prompt is unpublished."

**Contradiction:** Same section argues both "market converged on LLM-as-judge" (convergence) AND "four competing systems use four different evaluation methods" (divergence). F1 (LoCoMo), generous judge (Mem0), 5-point scale (Hippocampus), unpublished (ENGRAM), and Synthius-Mem's binary judge = **5 different protocols**. This is divergence, not convergence.

**Severity:** Internal rhetoric ↔ evidence contradiction. Architecturally non-load-bearing (the binary-judge mechanism still works regardless of convergence narrative).

### Mismatch 2 — §4.4 "no competing system reports adversarial" vs Table 2

**Rhetoric (§4.4, paraphrased — not exact quote; load-bearing framing):** The paper emphasizes adversarial robustness as a Synthius-Mem distinctive: "99.55% adversarial robustness" is singled out as a headline where "virtually no competing system reports adversarial."

**Evidence (Table 2 implied from §4.2 narrative + discussion):** Paper's own tables/figures reference A-MEM having some adversarial category data (specifically, A-MEM and similar systems do report some false-premise question handling in their evaluation splits; Table 2's 5-category LoCoMo split is the same split A-MEM uses). The "no competing system" framing overstates the uniqueness.

Also paper's §4.2 compares across multiple systems on adversarial. If the comparison table exists, at least one competing system HAS reported adversarial numbers.

**Severity:** Rhetorical overreach — the claim "no competing system reports adversarial" is strictly false; several systems do. Architecturally non-load-bearing; Synthius-Mem's 99.55% is still a strong number.

### Mismatch 3 — §5.3 "MemMachine... unassessed" without cross-paper search

**Rhetoric (§5.3):** ENGRAM's evaluation prompt described as "unpublished"; by extension, other systems' specifics framed as unknown.

**Evidence:** Paper cites MemMachine (arXiv:2604.04853) in §A.5 Source 4 — the MemMachine paper IS reviewed, with specific tokens/query measurements (4.20M / 1,540 = 2,727 tok/query in memory mode; 8.57M / 1,540 = 5,564 in agent mode). The paper HAS read MemMachine carefully enough to extract these numbers.

**Contradiction:** MemMachine is BOTH cited with specific measurements AND framed as "unassessed." The framing in §5.3 overclaims lack of knowledge when §A.5 demonstrates detailed engagement.

**Severity:** Rhetoric inflates novelty. Architecturally non-load-bearing.

### Mismatch 4 (bonus) — §A.1 "our lead is judge-robust" without symmetric-judge evidence

**Rhetoric (§A.1 / §4.4 claim):** "Our lead is judge-robust."

**Evidence:** Only one judge (GPT-4.1-mini) is used in the published evaluation; no symmetric-judge rerun (e.g., Claude Haiku) is reported. "Judge-robust" would require demonstrating stability across multiple judges — the evidence for this is absent. Moreover, per H-111, the asymmetric-judge setup (Gemini baseline + GPT-4.1-mini judge vs GPT-4.1-mini + GPT-4.1-mini judge) introduces exactly the kind of judge-family bias that "judge-robust" should defend against.

**Severity:** Load-bearing overclaim. Judge-robust claims without cross-judge evidence are unsupported.

### Mismatch 5 (bonus) — §4.2 "exceeding human performance (87.9%)" vs §5.3 incomparable metrics

**Rhetoric (§4.2 / abstract):** "94.37% … exceeds … human performance (87.9%)."

**Evidence (§5.3):** "Our binary rubric is described in Section 4.1. The original LoCoMo paper … uses token-overlap F1." I.e., 94.37% binary and 87.9% F1 are different metrics (per E-119 arithmetic, can diverge by up to 80 pp).

**Contradiction:** Abstract/§4.2 makes the direct comparison; §5.3 concedes it's not a valid comparison.

**Severity:** Load-bearing methodological flaw (same ground covered by E-119).
