## Drafted Loader Pseudocode

```python
from __future__ import annotations
import json, time
from collections import defaultdict
from pathlib import Path
from typing import Any

DOMAINS = ("biography","experiences","preferences",
           "social_circle","work","psychometrics")

# Hot extracted fields per domain (subset — typically 3–5 per domain).
HOT_FIELDS: dict[str, tuple[str, ...]] = {
    "biography":     ("institution","employer","place_of_birth","year","category"),
    "experiences":   ("parent_event_id","start","end"),
    "preferences":   ("target","category","polarity"),
    "social_circle": ("primary_name","relationship"),
    "work":          ("employer","role","project"),
    "psychometrics": ("framework","trait"),
}

class PersonaStore:
    """In-memory per-persona store. Built at session start; served from RAM."""

    def __init__(self, persona_id: str):
        self.persona_id = persona_id
        # domain -> fact_id -> FactItem (authoritative store)
        self.facts: dict[str, dict[str, dict]] = {d: {} for d in DOMAINS}
        # domain -> (field, value) -> list[fact_id] (inverted index)
        self.index: dict[str, dict[tuple[str, Any], list[str]]] = {
            d: defaultdict(list) for d in DOMAINS
        }

    def load(self, root: Path) -> float:
        """Read 6 JSONs, build inverted indexes. Returns wall-clock seconds."""
        t0 = time.perf_counter()
        for domain in DOMAINS:
            path = root / f"{self.persona_id}/{domain}.json"
            data = json.loads(path.read_text())  # {persona_id, facts:[...]}
            for item in data["facts"]:
                fid = item["fact_id"]
                self.facts[domain][fid] = item
                # Index every hot field that's present.
                for fname in HOT_FIELDS[domain]:
                    v = item.get("fields", {}).get(fname)
                    if v is None:
                        continue
                    # Normalize scalar strings to lowercase; keep numbers as-is.
                    key = (fname, v.lower() if isinstance(v, str) else v)
                    self.index[domain][key].append(fid)
        return time.perf_counter() - t0

    def match(self, domain: str, field: str, value: Any) -> list[dict]:
        """O(1) amortized lookup: returns list of FactItem dicts."""
        key = (field, value.lower() if isinstance(value, str) else value)
        fids = self.index[domain].get(key, [])
        return [self.facts[domain][f] for f in fids]
```

## Check (a) — 6 JSON load at session start

Reads all 6 files sequentially. For a 2.5 MB persona:
- Each file ≈ 400–500 KB.
- `pathlib` read + `json.loads`: ~1–2 ms per 500 KB on modern SSDs + CPython 3.11.
- Total 6-file read + parse: **~10–15 ms**.

## Check (b) — Inverted index construction

- ~2,000 facts × ~4 hot fields per fact = **~8,000 dict inserts**.
- Python dict insert amortized ~100 ns.
- Total: **~0.8 ms**.

## Check (c) — Total bootstrap < 20 ms

10–15 ms (load+parse) + 0.8 ms (index) + ~1 ms overhead = **~15 ms**. ✓

Amortization: a 30-turn conversation at 21.79 ms per retrieval → total retrieval time ≈ 650 ms. Bootstrap ≈ 2% of session compute. Per-turn marginal cost: ~1 µs. ✓

## Check (d) — Subsequent lookups < 0.1 µs

Python dict lookup: ~50 ns for small dicts, ~100 ns for large. `key = (fname, v.lower())` adds ~50 ns. Total: **~100–150 ns per lookup**. ✓

## Check (e) — T-012 + T-016 satisfaction

- **T-012 typed fields:** the `(field, value)` hash keys ARE the typed atomic fields. No substring search. ✓
- **T-016 no-FK:** no cross-domain joins at storage; soft references (`parent_event_id`, `social_context[]`) resolved at application layer by a second dict lookup. ✓
