### 1. Citation-verifier pseudocode

```python
import re
from typing import List, Set, Tuple

# Pattern: [domain_prefix_nnn] where prefix is one of the 6 domains (3-letter mnemonic)
FACT_ID_PATTERN = re.compile(
    r"\[(bio|exp|pref|soc|wrk|psy)_[a-zA-Z0-9_]+\]")

def extract_cited_ids(answer: str) -> Set[str]:
    return set(m.group(0).strip("[]") for m in FACT_ID_PATTERN.finditer(answer))

def retrieved_id_set(per_domain_facts: Dict[str, List[FactItem]]) -> Set[str]:
    ids = set()
    for facts in per_domain_facts.values():
        for f in facts:
            ids.add(f.fact_id)
    return ids

def verify_citations(answer: str, per_domain_facts: Dict[str, List[FactItem]]
                     ) -> Tuple[bool, List[str]]:
    cited  = extract_cited_ids(answer)
    avail  = retrieved_id_set(per_domain_facts)
    confab = list(cited - avail)
    return (len(confab) == 0, confab)

def post_generation_hook(answer: str, per_domain_facts, retry_budget=1):
    ok, confab = verify_citations(answer, per_domain_facts)
    if ok:
        return answer
    if retry_budget > 0:
        # Deterministic re-run: lower temperature, emphasize citation rule
        retry_prompt = build_retry_prompt(confabulated_ids=confab)
        new_answer = answer_llm(retry_prompt, per_domain_facts, temperature=0.0)
        return post_generation_hook(new_answer, per_domain_facts, retry_budget=0)
    # Retry budget exhausted — refuse
    return "I don't have that information about {user_name} in my memory."
```

### 2. Fact-ID format convention

Each fact's `fact_id` is assigned a human-readable prefix:
- `bio_` = biography
- `exp_` = experiences
- `pref_` = preferences
- `soc_` = social_circle
- `wrk_` = work
- `psy_` = psychometrics

Followed by a 6-char ULID-derived suffix or sequential number.

Example: `bio_a1b2c3`, `wrk_01`, `psy_big5_open`.

The H-074 system prompt instructs the LLM to cite these IDs verbatim from the retrieved context (which H-076 formats with `"fact_id": "bio_a1b2c3"` keys exposed).

### 4. Cost analysis (O(answer_length))

### 5. Edge cases considered

- **Paraphrased citations** that lose the `[id]` format (e.g., "according to fact 5"): These are caught by the H-074 prompt's explicit "CITATION RULE — Every claim MUST be backed by a [fact_id] token" — the regex finds zero IDs, flags the output as uncited (a different failure mode, also handled by retry or refuse). ✓
- **Partial IDs (`bio_0` when full is `bio_01`):** Regex uses `[a-zA-Z0-9_]+` which greedy-matches the full suffix; partial matches won't occur unless the LLM emits a truncated ID (rare under strict prompt).
- **IDs with whitespace/punctuation errors:** E.g., `[bio 01]` — regex requires underscore, rejects. LLM is heavily prompt-conditioned to emit exact format.
