## Drafted Artifacts

### 1. Planner function-call schema

```json
{
  "name": "plan",
  "description": "Emit a routing plan for the user question: which domains to query and per-domain predicates.",
  "parameters": {
    "type": "object",
    "additionalProperties": false,
    "properties": {
      "domains": {
        "type": "array",
        "items": {
          "type": "string",
          "enum": ["biography","experiences","preferences","social_circle","work","psychometrics"]
        },
        "minItems": 1, "maxItems": 6
      },
      "per_domain_query": {
        "type": "object",
        "additionalProperties": false,
        "patternProperties": {
          "^(biography|experiences|preferences|social_circle|work|psychometrics)$": {
            "type": "object",
            "additionalProperties": false,
            "properties": {
              "field": {"type": "string"},
              "value": {},
              "op": {"type":"string","enum":["eq","range","in"]}
            },
            "required": ["field","value","op"]
          }
        }
      }
    },
    "required": ["domains","per_domain_query"]
  }
}
```

### 2. Token accounting for the function-call schema

- `per_domain_query` with field/value/op schema: ~45 tok
- **Total: ~90 tokens.** ✓ Under the 100-tok budget.

### 4. Composition with T-025 and H-080 (assembler)

```python
def dispatch_plan(plan: Plan, persona_id: str) -> Dict[str, List[FactItem]]:
    results = {}
    for domain in plan.domains:
        q = plan.per_domain_query[domain]
        results[domain] = retrieve_tools[domain](
            persona_id=persona_id, field=q.field, value=q.value, op=q.op, limit=20)
    return results

# Assembler (H-080) concatenates per-domain results in planner-declared order
# with per-domain quota (T-026 2000/k rule).
```
