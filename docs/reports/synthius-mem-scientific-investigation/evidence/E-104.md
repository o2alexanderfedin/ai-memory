## Arithmetic

### 1. Linear-fit to Synthius-Mem data points (H-091 canonical)

Two paper-published points (Table 7 × N):
- (N=500, T=2,520,000)
- (N=1000, T=5,040,000)

Linear model: T(N) = α + β × N
- β = (T₂ − T₁) / (N₂ − N₁) = (5,040,000 − 2,520,000) / (1,000 − 500) = 2,520,000 / 500 = **5,040 tok/msg**
- α = T₁ − β × N₁ = 2,520,000 − 5,040 × 500 = **0** ← zero intercept

So: **T_Syn(N) = 5,040 × N** (pure linear, no constant term at N≥500).

### 2. Full-Context curve (quadratic)

Full Context adds the full history every turn:
- Turn 1: 1,200 tokens (sys + initial)
- Turn 2: 1,200 + 1,200 = 2,400 (appending prev turn)
- Turn N: 1,200 × N + overhead ≈ 50 tokens/turn × N + 1,200

Cumulative tokens over N turns:
- T_FC(N) = sum_{i=1..N} (50×i + 1,200) = 50×N(N+1)/2 + 1,200×N
- ≈ 25 × N² + 1,200 × N (for large N, quadratic dominates)

At N=500: T_FC ≈ 25 × 250,000 + 1,200 × 500 = 6,250,000 + 600,000 = **6,850,000** ≈ 6.9M ✓ (paper says "~6.9M")
At N=1000: 25 × 1,000,000 + 1,200 × 1,000 = 25,000,000 + 1,200,000 = **26,200,000** ≈ 26.2M ≈ paper's "27M" ✓ (within ~3%)

Per-message at N=500 for Full-Context: 6.9M / 500 = 13,800 tok/msg (matches Table 7's 26,200 "Total tok/msg at steady state at N=500" — wait, Table 7 says ~26,200 at steady state meaning the MESSAGE at turn N=500 alone is ~26K, not cumulative average).

Let me reconcile:
- Table 7 row "Full Context": additional input 25,000 + baseline ≈ 26,200 tok **per message AT N=500** (i.e., the 500th message has 25K history).
- Cumulative over all 500 messages: start from ~1,200 at msg 1, grow to 26,200 at msg 500 → arithmetic mean ≈ 13,700 × 500 = 6.85M ≈ **6.9M** ✓.

Model validated: **T_FC(N) ≈ 25×N² + 1,200×N**, quadratic.

### 3. Crossover computation

Synthius-Mem cost includes a one-time extraction cost (370K tokens across 500 msgs = 740/msg amortized but concentrated up front). Full Context has no extraction; just cumulative turns.

For N < 500 where extraction does NOT yet amortize, Synthius-Mem at message i costs:
- ~4,300 tok/msg steady-state (5,040 - 740 extraction floor)
- + extraction prorated differently for small N

Crossover condition: T_Syn(N) = T_FC(N)
- 5,040 × N = 25×N² + 1,200×N
- 25×N² - 3,840×N = 0
- N × (25×N - 3,840) = 0
- N = 0 or N = 3,840/25 = **153.6**

**Crossover ≈ N = 154** messages under a pure-linear model for Synthius-Mem (not 15 as H-104 predicted — H-104's figure appears off by 10×).

Correcting H-104's crossover: at N ≈ 154 messages, Synthius-Mem and Full Context have equal cumulative cost. Below N=154, Full Context is cheaper (no extraction up-front); above N=154, Synthius-Mem wins and grows linearly while Full Context grows quadratically.

### 5. Extraction amortization floor

Extraction cost: 370,000 tokens total, regardless of N (assumed batch all-at-once).
- At N=500: 370K/500 = 740 tok/msg amortized ✓ (Table 7)
- At N=1000: 370K/1000 = 370 tok/msg amortized (extraction amortizes further at higher N)
- At N=200: 370K/200 = 1,850 tok/msg (extraction dominates at small N)

So strictly, **Synthius-Mem is super-linear (slowing down slope) for N > 500**, approaching an asymptote:
- T_Syn(N) ≈ 370K + 4,300 × N (as N → ∞, slope → 4,300)
- At N=1000: 370K + 4.3M = **4.67M** (less than linear-model prediction of 5.04M)
- Paper says cumulative at N=1000 is **5.04M (Table 7 × N under H-091) or 4.7M under A.2** 
- **4.67M from asymptotic model is closer to A.2's 4.7M than to H-091's 5.04M** ← this is interesting

But paper's own A.1 says "per-message cost decreases as N grows (extraction amortizes), yielding sublinear cumulative growth" — confirming the model is sublinear past extraction amortization, not strictly linear.

### 6. Reconciliation with H-104's "α=0, β=5040" fit

H-104's strict linear fit (β=5040, α=0) uses the two published points:
- (500, 2.52M) and (1000, 5.04M) → β=5040, α=0.

But this assumes Table 7's 5040 reflects an amortized-at-N=500 figure. At N=1000 per Table 7 + §A.2 ("per-message cost decreases as N grows"), per-message would be LOWER than 5040, meaning the actual T at N=1000 should be < 5040×1000 = 5.04M. App. A.2's 9.3M contradicts that direction — another sign A.2 is anomalous.

**Conclusion:** H-104's linear model β=5,040 is a first-order approximation. A more accurate model is **T_Syn(N) = 370,000 + 4,300 × N** for N ≥ 500.
