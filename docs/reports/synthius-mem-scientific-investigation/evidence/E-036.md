## Drafted retrieval-tool pseudocode

```python
import unicodedata, re

PUNCT_RE = re.compile(r"[^\w\s]", flags=re.UNICODE)
WS_RE    = re.compile(r"\s+")

def normalize(s: str) -> str:
    """Deterministic canonicalization applied on both query-side and build-side."""
    if s is None: return ""
    s = unicodedata.normalize("NFKC", s)          # canonical Unicode
    s = s.casefold()                              # locale-stable lowercase
    s = PUNCT_RE.sub(" ", s)                      # strip punctuation
    s = WS_RE.sub(" ", s).strip()                 # collapse whitespace
    return s

# Per-domain alias tables — seeded from paper-named entities only (T-015).
ALIAS_TABLES: dict[str, dict[str, set[str]]] = {
  "social_circle.names": {
      "melanie": {"mel"},
      "robert":  {"bob", "rob", "bobby"},
      "william": {"will", "bill", "billy"},
      "caroline":{"caro", "carol"},
      "elizabeth":{"liz","beth","eliza","betty"},
  },
  "biography.institution": {
      "university college london": {"ucl"},
      "massachusetts institute of technology": {"mit"},
      "university of california berkeley": {"uc berkeley","berkeley","ucb"},
  },
  "work.employer": {
      "faang": {"google", "apple", "meta", "amazon", "netflix"},
      "alphabet": {"google"},
      "meta": {"facebook"},
  },
}

def expand(domain_field: str, value: str) -> set[str]:
    """Return {canonical} ∪ {aliases}. O(1): single dict probe on normalized value."""
    v = normalize(value)
    table = ALIAS_TABLES.get(domain_field, {})
    out = {v}
    # canonical -> aliases
    if v in table: out |= table[v]
    # alias -> canonical (reverse index pre-built once at startup)
    for canon, aliases in table.items():
        if v in aliases: out |= ({canon} | aliases)
    return out

def retrieve(domain: str, field: str, value, op: str = "eq", limit: int = 20):
    """CategoryRAG match step. No LLM. No embedding."""
    candidates = expand(f"{domain}.{field}", str(value)) if isinstance(value, str) else {value}
    hits = []
    for cand in candidates:
        # Index probe: `(persona_id, fields->>'institution')` B-tree (T-012/E-033).
        hits.extend(INDEX[domain][field].probe(op, cand))
    return sorted(hits, key=lambda h: (-h.confidence, -h.updated_at))[:limit]
```

## Latency arithmetic

Normalization: NFKC (~200 ns) + casefold (~50 ns) + punct regex on short strings (~500 ns) + whitespace (~150 ns) ≈ **~1 µs** per normalize call. Alias expansion: 1 dict probe + worst-case inverted-index scan over O(|table|) ≈ 10-50 entries × ~50 ns ≈ **~1-5 µs**. Index probe under T-016/E-033 functional B-tree on 200K rows: log₂(200,000) × ~50 ns ≈ **~1 µs**.

**Total match path: <10 µs per candidate; 5-alias fan-out → <50 µs total.** The 21.79 ms mean latency (§4.6) has ≈3 orders of magnitude of headroom over this match step, absorbing planner marshaling, JSON deserialize, and result assembly.
