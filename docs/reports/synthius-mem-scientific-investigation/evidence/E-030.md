**Experiment:** E-030 (artifact-construction) — Hypothesis H-030 (Postgres-JSONB storage substrate)
**Pass criterion:** Postgres DDL with 6 tables shaped `{persona_id, fact_id, schema_version, fields jsonb, envelope jsonb, created_at, updated_at}` + GIN(jsonb_path_ops) + functional B-tree; must (a) represent every Fig. 2 example losslessly, (b) satisfy T-012 typed fields + T-002 two-layer envelope + T-016 no-FK, (c) hit 21.79 ms at 200K rows with headroom, (d) fit 500 MB on commodity single node.

## Drafted Postgres DDL

```sql
-- Common envelope stored as JSONB for uniformity (T-003 CommonEnvelope).
-- Six tables, one per domain. NO FOREIGN KEY CONSTRAINTS cross-domain (T-016).

CREATE TABLE biography (
  persona_id     UUID         NOT NULL,
  fact_id        UUID         NOT NULL,
  schema_version TEXT         NOT NULL,
  fields         JSONB        NOT NULL,  -- decomposed typed sub-fields (T-012)
  envelope       JSONB        NOT NULL,  -- {confidence, provenance, category}
  created_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
  updated_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_bio_gin       ON biography USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_bio_inst      ON biography (persona_id, (fields->>'institution'));
CREATE INDEX idx_bio_year      ON biography (persona_id, ((fields->>'year')::int));
CREATE INDEX idx_bio_category  ON biography (persona_id, (envelope->>'category'));

CREATE TABLE experiences (
  persona_id      UUID NOT NULL, fact_id UUID NOT NULL,
  schema_version  TEXT NOT NULL,
  fields          JSONB NOT NULL,   -- {summary, start, end, parent_event_id, children[], social_context[], emotions[], intensity}
  envelope        JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_exp_gin    ON experiences USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_exp_parent ON experiences (persona_id, (fields->>'parent_event_id'));
CREATE INDEX idx_exp_range  ON experiences (persona_id, ((fields->>'start')::timestamptz));

CREATE TABLE preferences (
  persona_id UUID NOT NULL, fact_id UUID NOT NULL,
  schema_version TEXT NOT NULL,
  fields   JSONB NOT NULL,   -- {target, polarity, strength, category}
  envelope JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_pref_gin    ON preferences USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_pref_target ON preferences (persona_id, (fields->>'target'));

CREATE TABLE social_circle (
  persona_id UUID NOT NULL, fact_id UUID NOT NULL,  -- fact_id == person_id
  schema_version TEXT NOT NULL,
  fields   JSONB NOT NULL,   -- {names[], aliases[], relationship, closeness, trust}
  envelope JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_soc_gin   ON social_circle USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_soc_names ON social_circle USING GIN ((fields->'names') jsonb_path_ops);

CREATE TABLE work (
  persona_id UUID NOT NULL, fact_id UUID NOT NULL,
  schema_version TEXT NOT NULL,
  fields   JSONB NOT NULL,   -- {project, role, employer, teammates[], start, end}
  envelope JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_work_gin      ON work USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_work_employer ON work (persona_id, (fields->>'employer'));

CREATE TABLE psychometrics (
  persona_id UUID NOT NULL, fact_id UUID NOT NULL,
  schema_version TEXT NOT NULL,
  fields   JSONB NOT NULL,   -- {framework, trait, score, evidence_quote, facets?}
  envelope JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (persona_id, fact_id)
);
CREATE INDEX idx_psy_gin ON psychometrics USING GIN (fields jsonb_path_ops);
CREATE INDEX idx_psy_fw  ON psychometrics (persona_id, (fields->>'framework'), (fields->>'trait'));
```

## Check (a) — Fig. 2 Example Serialization (lossless)

| Fig. 2 datum | Serialization |
|---|---|
| "PhD Neuroscience, UCL, 2019" | `fields={degree:"PhD",field:"Neuroscience",institution:"UCL",year:2019,precision:"year"}` |
| Experience "Ran marathon" | `fields={summary:"Ran NYC marathon",start:"2023-11-05",emotions:["joy","anticipation"],intensity:0.8}` |

| Psychometrics Big Five Openness | `fields={framework:"BigFive",trait:"Openness",score:72,evidence_quote:"...",confidence:0.8}` |

All representable as JSONB payloads; no `additionalProperties:true` required. ✓

## Check (b) — T-012, T-002, T-016 compatibility

- **T-012 typed decomposition:** `fields` is JSONB with decomposed typed sub-fields indexed via GIN + functional B-tree (typed casts: `::int`, `::timestamptz`). ✓
- **T-002 two-layer envelope:** row = outer `(persona_id, fact_id, envelope)`; `fact_id` iterates `facts[]` conceptually. The (persona_id, domain-table) pair is the outer envelope; the row body is FactItem. ✓
- **T-016 no-FK:** No `REFERENCES` clauses across tables. `parent_event_id` and `teammates[]` are soft references validated at application layer. ✓

## Check (c) — Latency arithmetic at 200K rows

- 500 MB / ~2.5 KB per JSONB row ≈ 200,000 facts total (aggregate).
- Per-persona facts: 200K / ~200 personas = ~1,000 facts/persona/domain.
- B-tree probe on `(persona_id, (fields->>'institution'))`: log2(200,000) ≈ 17.6 comparisons × 50 ns cached = **~0.9 µs**.
- GIN containment `fields @> '{"institution":"UCL"}'`: bitmap + heap access ≈ **100–300 µs** on cached pages.
- Query planning: ~300 µs. Network/libpq marshaling: ~200 µs.
- Total hot path: **< 1 ms**, well under 21.79 ms. Headroom: >20×. ✓

## Check (d) — 500 MB fits commodity node

500 MB fits comfortably in a single 16 GB RAM node with room for OS cache. Postgres routinely handles TB-scale JSONB. ✓
