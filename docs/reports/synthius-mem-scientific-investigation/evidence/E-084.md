### 1. EWMA update pseudocode

```python
ALPHA_DEFAULTS = {
    "BigFive":          0.10,   # stable traits; slow drift
    "Schwartz":         0.10,   # core values; very slow
    "MFT":              0.10,
    "PoliticalCompass": 0.15,   # mildly faster drift
    "VIA":              0.15,
    "IRI":              0.15,
    "Kohlberg":         0.05,   # very slow (life-long)
    "CognitiveAbility": 0.05,   # very slow
    "PANAS":            0.30,   # state-like (mood); faster
}

def ewma_update_trait(framework: str, trait: str,
                      old_score: float, delta_from_new_evidence: float) -> float:
    alpha = ALPHA_DEFAULTS[framework]
    return alpha * delta_from_new_evidence + (1 - alpha) * old_score
```

### 2. McCrae & Costa longitudinal citation

McCrae & Costa (e.g., *Personality in Adulthood*, 2003; NEO-PI-R manual) established that Big Five traits show rank-order stability ~0.7 over 10-year intervals in adults, with slow mean-level drift. EWMA with α=0.1 per consolidation batch implicitly models this by reducing the weight of any single observation to 10%, requiring many consistent observations to shift the score substantially. ✓

Caveat: McCrae & Costa's data are from structured administrations (NEO-PI-R questionnaires) at multi-year intervals, not conversation-derived ad-hoc observations at hourly cadence. The α=0.1 is an *analog* to longitudinal stability, not a direct derivation. This is a modeling assumption, not an empirical fit.

### 4. Worked example — 3-step evolution

Initial state (time T1): BigFive.Agreeableness = 65.

**Step 1:** 50 new messages arrive with many "we" pronouns + helpful-tone. Delta score = 82. After EWMA: `0.1 × 82 + 0.9 × 65 = 66.7`.

**Step 3:** 50 new messages, neutral-to-helpful. Delta = 72. After EWMA: `0.1 × 72 + 0.9 × 64.83 = 65.55`.

Series: 65 → 66.7 → 64.83 → 65.55. Stable but adapting. ✓

### 5. α tuning rationale

Per framework:
- Very slow traits (Big Five, Schwartz, MFT, Kohlberg, g): α ≤ 0.15 — reflects decades-long stability.
- Mildly faster (political views, VIA strengths, empathy): α ∈ [0.1, 0.2] — can shift with life events.
- State-like (PANAS mood): α ≥ 0.3 — captures transient emotional state.

### 6. Trades reproducibility for efficiency

EWMA is path-dependent: the final score depends on the *order* in which evidence batches arrived. Two users with identical total evidence but different batch orderings will have different EWMA scores. This breaks reproducibility-given-full-history (H-083 has this property; H-084 does not).

Efficiency: 10× input token reduction per scoring call. ✓

### Secondary clause:
> FAIL if evidence-quote selection (G-050) requires re-scanning the full corpus (incompatible with incremental EWMA)

THIS IS THE CRITICAL ISSUE. Per H-085 (E-085), psychometric output includes `top_evidence: [quote, quote, quote]`. Under EWMA:
- If evidence quotes are selected from **only the new evidence batch**: the top-3 quotes will drift over time, losing the strongest historical quotes unless explicitly preserved.
- If evidence quotes are selected by **re-scanning the full corpus**: the incremental-EWMA advantage collapses — you've paid the full-scan cost anyway, negating H-084's cost savings.

Neither branch is clean. **The evidence-quote requirement creates serious friction with EWMA.**

Options:
- Keep a running "top-N evidence" heap across batches (maintain top-3 by LLM-assigned salience across all batches seen). Memory-bounded, but requires tracking an extra structure.
- Separate the score-update (EWMA) from the evidence-quote-refresh (periodic full-scan). Two different cadences — adds complexity.

These options are buildable but significantly complicate H-084's "simpler than H-083" argument. The efficiency advantage is also partially eroded because evidence-quote-refresh still requires periodic full-scans.
