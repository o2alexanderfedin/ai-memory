7. **Biometric inference** (voice / typing cadence / face from attachments) — DO-NOT-STORE;

## (b) Inspect endpoint spec

```yaml
GET /persona/{persona_id}/psychometrics
  auth: persona-owner (or tenant-admin with scoped delegation)
  response:
    - framework: str  # e.g., "Big_Five"
      trait: str      # e.g., "Agreeableness"
      score: float    # 0..100 (T-008 numeric confidence NOT same axis)
      confidence: float  # 0..1 (T-008)
      confidence_label: "high" | "medium" | "low"
      evidence_quotes: [str]  # from T-009 provenance, top-3 (T-062)
      extracted_at: ISO-8601
      extractor_version: str
      last_updated_at: ISO-8601
      act_on_policy:
        adapt_answer_style: "ALLOW" | "DENY"
        adapt_content_filter: "DENY"  # always
        # ... (full act-on policy row)
      user_suppressed: bool  # H-134 suppress endpoint state
```

Satisfies GDPR Art. 15 (right of access): user can see every stored trait score, confidence,
evidence quotes, extraction metadata, and current act-on policy.

## (c) Suppress / freeze endpoint spec

```yaml
POST /persona/{persona_id}/psychometrics/suppress
  auth: persona-owner
  request:
    - framework: str
      trait: str?  # if null, suppress entire framework
      mode: "suppress" | "freeze" | "delete"
  response:
    - framework: str
      trait: str
      applied_at: ISO-8601
      effective_immediately: true  # answer-LLM stops reading next request
```

- **suppress** = trait stored but NOT injected into answer-LLM system prompt (T-057).
- **freeze** = trait stored, current value frozen, not updated on further consolidations.
- **delete** = trait deleted via H-137 crypto-shredding or H-140 tombstone-purge.

Effect on T-057: suppressed traits are omitted from the `"User personality: {...}"` block.
Immediate effect on next answer-LLM call.

by default; Political / Moral / Kohlberg / IQ are STORED but SUPPRESSED at injection.
